How it works

Four steps, no sign-in. The link is rebuilt right in your browser.

  1. 1. Share the file publicly

    In Google Drive, open Share, set General access to “Anyone with the link”, and keep the role as Viewer.

  2. 2. Paste the share link

    Copy the link from Drive. It looks like https://drive.google.com/file/d/FILE_ID/view.

  3. 3. Pick a link type

    Choose Download link to start a file download, or Image preview link to use a picture on a website.

  4. 4. Copy and use it

    Paste the result anywhere: a button, an <img src> tag, a README, or a chat.

Remember: Anyone with the converted link can open the file, so only convert files you’re fine making public.
